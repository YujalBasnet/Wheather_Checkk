# Weather Pulse

A small Python + HTML/CSS weather checker for Nepal cities only.

## Features
- Search weather by Nepal city name
- Live weather data via Open-Meteo
- Responsive and modern UI
- No weather API key required

## Run locally
1. Create and activate a virtual environment.
2. Install dependencies:
   pip install -r requirements.txt
3. Start the app:
   python app.py
4. Open your browser at:
   http://127.0.0.1:5000

## Tech stack
- Python (Flask)
- Vanilla HTML/CSS/JavaScript
- Open-Meteo APIs (geocoding + forecast)
